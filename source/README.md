# Private sources (not on GitHub)

This repository is public, so the house plans and photos are kept out of it on purpose.

- `plans/plans-review-set-2026-06-02.pdf` — the plan set the structure is traced from. Needed only to rebuild
  `site/house.json` with `./build.sh`.
- `photos/` — the owner's photos and videos (the source for finishes and furniture).

Both folders are listed in `.gitignore`. Keep the originals somewhere private and copy them here when working.
