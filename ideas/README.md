# Ideas (not real)

Everything in this folder is a **proposal**, not the house as it is.

Rules:
- Never change the real model (`site/house.json`, the real built-ins in `site/index.html`, `source/`) to try an idea.
- Each idea gets its own folder, e.g. `ideas/2027-01-living-room-sofa/`, with a short `idea.md` saying what it
  changes, where, and why, plus any models or materials it uses.
- In the viewer, ideas load as a separate layer that is **off by default** and clearly labeled "Idea", so the real
  house is always what you see first.
- When an idea becomes real (you actually buy or build it), it moves into the real model and the photos confirm it.
